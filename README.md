Shrbot is a discord bot that sends pictures (originally made for pictures of cat from my friend *shrbo* (hense the name)) 

How to use:

    Clone the repo
  
    Install the deps 
  
    Rename `templateenv.txt` to `.env`, add your bot token to the `DISCORD_API_KEY` field and the path to the images you want to send to the `IMAGE_PATH` field 
  
    Execute the bot
